# README screenshots

`search.png` and `project.png` were captured from the running, unmodified Vortex
interface on September 27, 2026. The archive contained three fictional projects:
Atrium workspace, Harbor facade and Atlas drive assembly.

All notes and concept drawings were created for this demonstration. Files were
uploaded and indexed through the application using its real local embedding
models. Search results, scores and labels were not edited. The drawings are
illustrative examples, not engineering deliverables.

The screenshots contain no customer documents, personal accounts or production
data. The account shown as `demo` belongs only to the isolated demonstration.
The screenshot files contain no browser cookies or session credentials.

Visual captions and tags are selected from the app's fixed taxonomy and can be
inaccurate. The images demonstrate the interface, not measured retrieval quality.

To refresh them, start Vortex with a separate `VORTEX_DATA_DIR`, upload fictional
files, select the English interface, and capture the search and project views at
a 1440 × 1000 browser viewport. Do not use a personal or customer archive.
